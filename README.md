# Point Cloud Studio

**Open the app:** https://ollieh99.github.io/point-cloud-studio/

Turn photos, video and music into animated point clouds with in-browser AI depth (Depth Anything V2 Small), Swarm and Melt transitions, a timeline, music-reactive effects, and offline MP4/WebM/PNG export for your edit.

Everything runs locally in your browser: nothing you import is uploaded. It works best in a recent Chrome or Edge on a desktop or laptop (WebGPU and WebCodecs).

This repository contains the built web app only. Third-party licences and sample-media credits are in [NOTICE.md](NOTICE.md).
